# M3-L7 – Master: Numerical linear algebra – singular values and large systems of equations {#L7}

**Course area:** M3 – Master’s-oriented advanced studies

**Level:** Master’s orientation

**Prior knowledge:** No fixed prerequisites specified.

**Context:** Master’s-oriented advanced study following M1-L5, M1-L6, M1-L8, M3-L2 and M3-L6

## What is this about? {#S1}

If a matrix has only two rows, we can solve a system of linear equations by hand. In AI, simulation and optimisation, however, matrices often have millions of entries. In these cases, **memory requirements, computation time, conditioning and numerical stability** determine whether a mathematically correct formula is useful in practice. Numerical linear algebra therefore investigates not only *which* solution exists, but also *how reliably* we can obtain it with finite computational precision. Two central tools are the **singular value decomposition (SVD)** and **Krylov methods**.

## Basic idea and intuition {#S2}

A matrix can map a circle of input vectors onto an ellipse. Some directions are stretched considerably, others only slightly. The **singular values** quantify these stretches. If a direction is almost completely compressed, small measurement errors can be greatly amplified when reversing the transformation. For large sparse matrices, we therefore use methods that gradually approximate a result through repeated **matrix–vector products**, rather than storing a full inverse matrix.

## New symbols – read these first {#S3}

| Symbol | Read aloud | Meaning here | Do not confuse with |

| $\varepsilon$ | “epsilon” | A small positive number explicitly specified here | An error bound without context |
| $A^{\top}$ | “A transpose” | Rows and columns interchanged | Not automatically $A^{-1}$ |
| $U, V$ | “U and V” | Matrices with orthonormal columns | Arbitrary scaling matrices |

| $\sigma _{i}$ | “sigma sub i” | ith singular value, in descending order | Eigenvalues can be negative |

| $\Vert A\Vert _{2}$ | “operator two-norm of A” | Greatest stretch of a matrix | Not the same as the Frobenius norm |
| $\kappa _{2}(A)$ | “kappa two of A” | Condition number with respect to the two-norm | A measure of error sensitivity, not the solution itself |
| $A^{+}$ | “A plus” | Moore–Penrose pseudoinverse | Not always the actual inverse |
| $r_{k}$ | “residual vector r sub k” | Residual $b-Ax_{k}$ at iteration k | The solution error $x^*-x_k$ |
| $K_{k}(A,r_{0})$ | “Krylov space of order k” | Space spanned by the residual vector and its repeated images under the matrix | Not a single iteration |
| $\alpha _{k}$, $\beta _{k}$ | “alpha/beta sub k” | Step size and direction weight in the CG method | Physical angles |

## Why direct formulae are insufficient for large matrices {#S4}

A system of linear equations is written as:

$$
A\,x=b\text{.}
$$

Read aloud: “The matrix A maps the unknown vector x onto the known right-hand-side vector b.” If A is square and invertible, then theoretically $x=A^{-1}b$. **For the numerical task of simply solving the system, one should generally not explicitly compute the inverse matrix.** Better alternatives include QR or LU factorisation and, for very large sparse problems, suitable iterative methods. Even an exact mathematical solution can be poorly determined numerically if A is nearly singular.

*Sparse* means that many matrix entries are zero. Storing only non-zero entries and their positions can greatly reduce memory requirements. An algorithm that unnecessarily constructs the entire dense matrix destroys this advantage.

## The singular value decomposition (SVD) {#S5}

Every real m-by-n matrix has an SVD. In full form:

$$
A=U\Sigma V^{\mathrm{T}}\text{.}
$$

Read aloud: “A results from an orthogonal rotation or reflection of coordinates by V transpose, followed by stretching along the axes by sigma and a further orthogonal transformation by U.” Here U and V are orthogonal (with appropriate dimensions for rectangular matrices); the diagonal of Σ contains the non-negative singular values $\sigma _{1}\ge \sigma _{2}\ge \ldots \ge 0$. A *thin SVD* uses only the required columns.

The positive squares of the singular values are the positive eigenvalues of $A^{\top}A$. The eigenvalues of the original matrix A, on the other hand, are **not** the same as its singular values; a non-square matrix has no ordinary eigenvalues at all.

### Fully worked example: stretching in selected directions {#abschnitt-6}

$$
\begin{aligned}
A&=\begin{bmatrix}2&0\\0&1\end{bmatrix},
\quad U=\begin{bmatrix}1&0\\0&1\end{bmatrix}\\
\Sigma&=\begin{bmatrix}2&0\\0&1\end{bmatrix},
\quad V=\begin{bmatrix}1&0\\0&1\end{bmatrix}\\
A^\top A&=\begin{bmatrix}4&0\\0&1\end{bmatrix}
\end{aligned}
$$

The example is deliberately simple. The eigenvalues of $A^{\top}A$ are four and one. Their non-negative square roots are the singular values **2 and 1**. A unit vector along the first coordinate doubles in length; along the second, its length remains unchanged. Thus $\Vert A\Vert _{2}=2$, the smallest singular value is one and $\kappa_2(A)=\frac21=2$.

For a matrix with full column rank, the two-norm condition number is the ratio of the largest to the smallest singular value. **The larger this ratio, the more sensitive the inverse operation can be to perturbations.** A specific error bound additionally requires information about the perturbation model. If a **square** matrix A has a zero singular value, it is not invertible; the condition number for the invertible-system problem is then regarded as infinite. For **rectangular** matrices, by contrast, the issue is full column rank or pseudoinversion, rather than an ordinary two-sided inverse.

## Low rank, compression and the pseudoinverse {#S6}

In many images, sensor matrices and embedding tables, only a few directions carry useful information. We can truncate the SVD after the r largest singular values:

$$
A_r=\sigma_1u_1v_1^{\mathrm{T}}+\sigma_2u_2v_2^{\mathrm{T}}+\cdots+\sigma_ru_rv_r^{\mathrm{T}}\text{.}
$$

Read aloud: “The rank-r approximation A sub r is the sum of the r most important rank-one components.” The **Eckart–Young–Mirsky** theorem states that this truncated SVD is a best approximation among all matrices of rank at most r, in both the operator two-norm and the Frobenius norm. In the two-norm, the error is $\sigma_{r+1}$; in the Frobenius norm, its square is the sum of the squares of the discarded singular values. In the event of ties, the best approximation need not be unique.

For our matrix $\operatorname{diag}(2,1)$, the rank-one approximation is $\operatorname{diag}(2,0)$. The error $\operatorname{diag}(0,1)$ has a two-norm of one. This also shows the limitation: compression saves data but loses information from the second direction.

### Rank deficiency without an arbitrary choice {#abschnitt-8}

Consider:

$$
\begin{aligned}
A&=\begin{bmatrix}1&1\\2&2\end{bmatrix},
\quad b=\begin{bmatrix}3\\6\end{bmatrix}
\end{aligned}
$$

The two columns are identical; the rank is one. Every solution satisfies $x_{1}+x_{2}=3$. There are therefore infinitely many solutions, for example $(3,0)$, $(0,3)$ and $(1{,}5;1{,}5)$. For a consistent system, the **Moore–Penrose pseudoinverse** selects the solution with the smallest Euclidean norm:

$$
\begin{aligned}
A^+&=\frac1{10}\begin{bmatrix}1&2\\1&2\end{bmatrix}\\
x&=A^+b=\frac1{10}\cdot{[3+12,3+12]}^\top={[1{,}5;1{,}5]}^\top\text{.}
\end{aligned}
$$

Read aloud: “We multiply the pseudoinverse by the right-hand-side vector and obtain two equal components whose sum is three.” For **inconsistent** systems, $A^{+}b$ gives a solution with the smallest squared residual norm and, among these solutions, one with the smallest norm. Pseudoinverses are no substitute for examining uncertainty and the choice of model.

## Why normal equations can be sensitive {#S7}

For an overdetermined problem $Ax\approx b$, one often minimises ${\Vert Ax-b\Vert}_2^2$. A formal stationarity argument gives:

$$
A^{\mathrm{T}}A\,x=A^{\mathrm{T}}b\text{.}
$$

Read aloud: “We multiply the original equation on the left by A transpose.” If A has full column rank, $A^{\top}A$ is invertible. However, in the two-norm we then have:

$$
\kappa_2(A^{\mathrm{T}}A)={\kappa_2(A)}^2\text{.}
$$

Read aloud: “The condition number of the normal-equation matrix is the square of the condition number of the original matrix.” Even moderate sensitivity can therefore increase considerably. **QR decomposition and SVD** are consequently more robust for many least-squares calculations, although they require computation time and memory. The amplification can be verified directly using $A=\operatorname{diag}(1;0{,}001)$: $\kappa_2(A)=1\,000$, while $A^\top A=\operatorname{diag}(1;0{,}000001)$ has the condition number $1\,000\,000$. These figures concern the mathematical conditioning of the matrices, not automatically the actual deviation of every numerical solver. For large sparse problems, iterative least-squares methods such as LSQR may again be appropriate.

## Krylov spaces – solving a system step by step {#S8}

Let A be a square matrix, $x_{0}$ an initial estimate and $r_{0}=b-Ax_{0}$ its residual. A Krylov space collects the directions produced by the repeated action of A on the residual:

$$
K_k(A,r_0)=\operatorname{span}\{r_0,Ar_0,A^2r_0,\ldots,A^{k-1}r_0\}\text{.}
$$

Read aloud: “The Krylov space of order k comprises all linear combinations of the initial residual vector, its image after one application of the matrix, its image after two applications, and so on up to the power k minus one.” $\operatorname{span}$ means *linear span*. A Krylov method searches for an improved approximation in $x_{0}+K_{k}(A,r_{0})$. Importantly, this usually requires **matrix–vector products**, not all matrix entries as a dense copy.

**Conjugate gradient (CG)** is particularly efficient when A is real, symmetric and positive definite. **GMRES** is applicable to more general non-singular matrices; it minimises the residual over the relevant Krylov subspace, but must store basis vectors for large iteration counts. Restarting reduces memory requirements and may impair convergence. Suitability always depends on the problem.

## Fully worked CG example {#S9}

We solve the system $Ax=b$ with:

$$
\begin{aligned}
A&=\begin{bmatrix}4&1\\1&3\end{bmatrix},
\quad b=\begin{bmatrix}1\\2\end{bmatrix},
\quad x_0=\begin{bmatrix}0\\0\end{bmatrix}
\end{aligned}
$$

A is symmetric. The leading principal minors, four and eleven, are positive; for this symmetric $2\times2$ matrix, positive definiteness follows. We may use CG.

**Start:** The residual is $r_0=b-Ax_0={(1,2)}^\top$; the first direction is $p_{0}=r_{0}$. We need the scalar product $r_{0}^{\top}r_{0}=1^{2}+2^{2}=5$ and the matrix product $Ap_0={(6,7)}^\top$. Hence $p_{0}^{\top}Ap_{0}=1\cdot 6+2\cdot 7=20$.

$$
\begin{aligned}
\alpha_0&=\frac{r_0^\top r_0}{p_0^\top A p_0}=\frac5{20}=\frac14\text{.}\\
x_1&=x_0+\alpha_0p_0=\left(\frac14,\frac12\right)^\top\text{.}\\
r_1&=r_0-\alpha_0Ap_0=\left(-\frac12,\frac14\right)^\top\text{.}
\end{aligned}
$$

Read aloud: “The first step size is one quarter. We move by one quarter of the initial residual towards the solution. The new residual vector has minus one half as its first component and plus one quarter as its second component.” Its squared norm is $\frac14+\frac1{16}=\frac5{16}$.

**New direction:** The direction weight $\beta _{0}$ is the ratio of the new to the old squared residual norm:

$$
\begin{aligned}
\beta_0&=\frac{r_1^\top r_1}{r_0^\top r_0}=\frac{5/16}{5}=\frac1{16}\text{.}\\
p_1&=r_1+\beta_0p_0=\left(-\frac7{16},\frac38\right)^\top\text{.}\\
\alpha_1&=\frac{r_1^\top r_1}{p_1^\top A p_1}=\frac4{11}\text{.}\\
x_2&=x_1+\alpha_1p_1=\left(\frac1{11},\frac7{11}\right)^\top\text{.}
\end{aligned}
$$

Read aloud: “We add a small proportion of the previous search direction to the new residual. The second step gives exactly one eleventh and seven elevenths.” Verification:

$$
A\,x_2=\left(\frac{4+7}{11},\frac{1+21}{11}\right)^{\mathrm{T}}={(1,2)}^{\mathrm{T}}=b\text{.}
$$

In **exact arithmetic**, CG reaches the exact solution for an n-by-n SPD matrix after at most n suitable iterations. In practical floating-point arithmetic, rounding errors can affect this result; convergence tests and preconditioning remain important.

## Residual, actual error and preconditioning {#S10}

A small residual is desirable but is not the same as a small solution error. With the exact solution $x^*$, the following holds for invertible A:

$$
\begin{aligned}
r&=b-Ax=A(x^*-x),\\
\lVert x^*-x\rVert_2&\le\lVert A^{-1}\rVert_2\cdot\lVert r\rVert_2\text{.}
\end{aligned}
$$

Read aloud: “The actual error is bounded above by the size of the inverse matrix and the size of the residual.” If A is ill-conditioned, an apparently small residual can therefore correspond to a considerable error.

### Counterexample: small residual, large error {#abschnitt-13}

Let us choose an **invertible** but strongly stretched matrix with $\varepsilon =0{,}0001$:

$$
\begin{aligned}
A&=\operatorname{diag}(1,\varepsilon),\quad x^*={(1,1)}^\top,\quad b={(1,\varepsilon)}^\top\\
\text{Approximation }x&={(1,0)}^\top,\quad r=b-Ax={(0,\varepsilon)}^\top\text{.}\\
\lVert r\rVert_2&=0{,}0001,\quad\lVert x^*-x\rVert_2=1\text{.}\\
\kappa_2(A)&=\frac1\varepsilon=10\,000,\quad\lVert A^{-1}\rVert_2=10\,000\text{.}
\end{aligned}
$$

Read aloud: “Although the residual of the equation is only one ten-thousandth in size, the second component of our solution is wrong by one.” The previously stated error bound gives exactly $1\le10\,000\cdot0{,}0001=1$ here; it is therefore sharp. This example concerns a precisely formulated linear problem. In applications, measurement errors and model uncertainties also arise.

**Preconditioning** transforms the system so that an iterative solver encounters more favourable spectral properties, without changing the substance of the original problem. It is problem-specific and itself incurs computational costs.

## What is it useful for? {#S11}

- **AI and data analysis:** dimensionally reduced data representations, stable linear models and large least-squares problems.
- **Robotics and simulation:** large sparse systems of equations from dynamics, FEM and state estimation.
- **Image and signal processing:** low-rank approximations for compression and noise reduction.
- **Numerical optimisation:** solving linear subproblems in Newton and interior-point methods.

## Assumptions and limitations {#S12}

An SVD always exists but is expensive for extremely large dense matrices; approximate or randomised variants require their own error analyses. The CG method requires **SPD**; non-symmetric or indefinite systems require other methods. Rank estimates depend on a meaningful tolerance relative to measurement and rounding precision. Conditioning, algorithmic stability and model error are distinct issues. The exact arithmetic shown in the examples does not guarantee an identical sequence of floating-point operations on arbitrary hardware.

## Key points to remember {#S14}

The **SVD** describes stretches and sensitive directions. **Conditioning** measures the sensitivity of the mathematical problem, while **stability** concerns the computational method. **Krylov methods** use matrix–vector products rather than forming a full inverse. A **small residual** is not an unconditional guarantee of accuracy without considering conditioning.
